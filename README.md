# Darkbound Platformer

Version 0.1.0 movement prototype for a dark side-scrolling action roguelite.

## Controls
- Keyboard: A/D or arrows, Space/W/Up to jump, Shift/K to dodge, Esc to pause.
- Xbox: left stick/D-pad, A to jump, B to dodge, Start to pause.
- iPhone: landscape touch controls.
